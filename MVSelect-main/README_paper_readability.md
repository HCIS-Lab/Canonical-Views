# Paper figure presentation update — 16 September 2026

These scripts rebuild the review figures from audited source tables. They do not train or evaluate models, and the scientific values and uncertainty definitions are unchanged. Run counts mean separate training runs, not objects or test repeats. The current paper uses the main cohort for Figures 1, 3, 4 and the earlier cohort for the explicitly labeled secondary analyses.

New presentation: standardized view-type example labels, blue/orange/gray families, redundant markers/line styles, visible y ticks in every Figure 3 panel, and plain replay labels. Original source CSV field names are retained.

No author command is required; final figures are supplied in the review package. Optional CPU reproduction from its source_data and assets directories:

```bash
python3 plot_paper_corrected_figures.py --data-dir /path/to/review/source_data --assets-dir /path/to/review/assets --output /path/to/review/figures
python3 plot_paper_e18.py --data-root /path/to/review/source_data --output /path/to/review/figures
```

Run in that order: the second script replaces the legacy Figure 5 generated by the first and supplies Extended Data 9 and Supplementary Figure 6. E18 accepts either original audit filenames or the e18_ prefixed review filenames. Python dependencies: numpy, pandas, matplotlib and Pillow. No GPU needed. Raw numerical files are read only.

The supplied object_examples.json must accompany the original renders when using the repository's paper_review_assets fallback. Use the explicit --assets-dir option to select the packaged originals instead.
